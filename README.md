# 🧭 CampusFound — Student Recovery Network

A modern, serverless real-time web application engineered to centralize and accelerate lost-and-found reporting across university campuses.

🔗 **Live Deployment:** [spideyart.github.io/campus-found](https://spideyart.github.io/campus-found/)

---

## 📌 Problem Statement
Traditional university lost-and-found communication relies heavily on unorganized WhatsApp/Telegram groups, leading to high message noise, lack of searchability, and delayed item recovery. **CampusFound** provides a single, structured interface where students can instantly report, filter, search, and resolve missing belongings.

---

## ✨ Core Features
* **⚡ Real-Time Cloud Sync:** Instant global feed updates powered by a cloud database backend.
* **🔍 Dynamic Client-Side Filtering:** Instant search by keywords, locations, or item categories without page reloads.
* **🏷️ Categorization System:** Separate views for `🔴 Lost` and `🟢 Found` items alongside dedicated tags (*Electronics, IDs, Books, Keys*).
* **💬 1-Click WhatsApp Direct Connect:** Facilitates fast, peer-to-peer verification and handoffs via auto-formatted communication links.
* **📱 Mobile-First Responsive Design:** Built with modern glassmorphism aesthetics and custom dark-mode typography.

---

## 🛠️ Tech Stack & Architecture
* **Frontend:** HTML5, Modern CSS / Tailwind CSS, Vanilla JavaScript (ES6+)
* **Backend & Database:** Supabase (PostgreSQL with Row Level Security)
* **API Architecture:** Serverless RESTful endpoints over HTTPS
* **Hosting:** GitHub Pages CI/CD
